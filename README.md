Welcome to my **100 Days of Python Code** Path! 🚀

This repository documents my journey learning Python following the course of 100 Days of Code from The App Brewery — one day, one commit, one small win at a time. The goal is simple: **show up daily, build real things, and track the progress publicly** so it holds me accountable and (hopefully) helps others learn along the way too.

---

## 📌 About This Challenge

The "100 Days of Code" challenge follows a simple rule:

> Code for a minimum of 1 hour every day for the next 100 days, and log your progress.

Each day I'll be tackling a new concept, mini-project, or exercise coming from the course — ranging from Python fundamentals to more advanced topics.

---

## 🎯 Goals

- ✅ Build consistency and discipline in coding daily

## 🚀 How to Run the Code

Clone the repo:

```bash
git clone https://github.com/mlmartello/python-100-days-of-code.git
cd python-100-days-of-code
```

Navigate into any day's folder and run the script:

```bash
cd day-1
python <project_name>.py
```

> 💡 Some days may require installing extra dependencies — check for a `requirements.txt` inside that day's folder.
